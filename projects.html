FitCheck

GitHub ↗ • Demo Video 🎥

Built out of a desire to eliminate morning decision fatigue, FitCheck is an automated wardrobe companion that turns your actual closet into a dynamic outfit generator. Built with React Native and Flask, it pairs a custom YOLOv8 model for real-time item detection with generative AI prompting to analyze wardrobe inventory and synthesize complete, styled outfit recommendations in seconds.

PantryPulse

GitHub ↗ • Demo Video 🎥

A local logistics matching platform built to take the guesswork out of community food distribution. Powered by a Python/Flask optimization backend, it dynamically routes surplus donations to pre-filed neighborhood pantries based on real-time inventory needs and location constraints.

StudyPod

GitHub ↗ • Demo Video 🎥

A full-stack web application that transforms study notes into engaging, two-speaker audio podcasts in seconds. Inspired by an effort to remediate my dangerous habit of reviewing notes while walking to an exam via an audio-based last minute studying attempt, StudyPod leverages a FastAPI backend, Groq LLMs for natural dialogue generation, and Edge-TTS with Pydub for multi-voice audio synthesis—all wrapped in a clean, responsive Tailwind CSS frontend.

Python Groq API Prompt Engineering Edge TTS + Pydub REST API
